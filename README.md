# ویجت تقویم شمسی

## ساخت APK (بدون نصب هیچ ابزاری)
1. یک ریپوی خالی در GitHub بسازید و محتوای این پوشه را push کنید (شاخهٔ main).
2. به تب Actions بروید؛ workflow «Build APK» خودکار اجرا می‌شود (حدود ۳–۵ دقیقه).
3. از بخش Artifacts فایل `JalaliWidget-apk` را دانلود کنید؛ داخلش `app-debug.apk` است.

## ساخت با Android Studio
پوشه را Open کنید، Gradle Sync بزنید، سپس Build ← Build APK(s).

## نصب و راه‌اندازی
APK را روی گوشی نصب کنید (اجازهٔ نصب از منبع ناشناس)، برنامه را باز کنید، چهار مجوز را بدهید،
سپس ویجت را از لیست Widgets صفحهٔ اصلی اضافه کنید.
